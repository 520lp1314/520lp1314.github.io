# 爱老婆拼豆坊

图片转拼豆图纸与逐格编辑器。

- 应用入口：`index.html`
- 图文说明书：`manual.html`
- Word 说明书：`manual.docx`

## 发布

在 GitHub 的仓库 Settings → Pages 中，选择 Deploy from a branch，选择 main 分支与根目录后保存。Pages 显示网站地址后，根地址打开应用，地址后加 manual.html 打开说明书。

本目录只包含网站成品与必要的第三方说明。所有应用依赖和色卡已内嵌，无需构建或后端。图片在浏览器本地处理，工程保存到当前浏览器；不含云同步。

GitHub Pages 地址没有预设到期时间；保留账号、仓库和 Pages 配置即可继续使用。托管服务或网络变化仍可能影响可用性。
